# UK Firestick 4K IPTV Setup Guide (2026 Walkthrough)

This repository provides open-source configuration walkthroughs for sideloading and optimizing 4K IPTV streaming applications on Amazon Fire TV Stick, Firestick 4K Max, and Fire TV Cube.

---

### 🚀 Recommended Setup Workflow

1. **Enable Developer Options:**
   * Go to `Settings` > `My Fire TV` > `About`.
   * Click your device name **7 times** until you see *"You are now a developer."*
2. **Install Downloader:**
   * Search for the official "Downloader" application on the Amazon Appstore and install it.
   * Under `Settings` > `Developer Options` > `Install unknown apps`, allow Downloader.
3. **Install Recommended 4K Player:**
   * Use Downloader to install your preferred player (TiviMate Premium or IPTV Smarters Pro).
4. **Connect Xtream Codes API:**
   * Enter your secure server URL, username, and password provided by your subscription.
